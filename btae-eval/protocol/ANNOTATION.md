# Ground Truth 与盲评规程

当前 evaluator-private/impact-draft.json 是 Agent 起草的文件级候选标注；没有独立专家身份、双人一致性或任务的参考修复，不能用作最终真值，也不支持类级效果宣称。

每条任务由两名未参与方法实现的标注者独立审阅初始代码、变更要求、依赖关系与公共契约，建立必要影响、条件性影响和应当不变的 negative controls。保存各自原始标注、依据位置与理由，再由第三人处理分歧；不要只保存达成一致的最终清单。报告集合一致率/Jaccard、分类的一致性指标及裁决比例。标注者不能先看各组结果再改真值。

区分：实现实体、契约实体、公开文档实体、验证行为；多语言用稳定符号 ID，重命名保持旧→新 lineage。当前草稿单位是 pre-existing file identity；新增文件、可替代合法实现与不同粒度不得用简单字符串对齐代替语义裁决。正式类级真值需进一步拆解。

影响预测必须在首次 patch 之前提交；由主控时间戳和文件哈希封存，事后更新只作为第二次预测而非覆盖。字符串集合去重，避免重复链接刷分；文档覆盖与链接语义 precision/recall 分开。不存在适用链接时记 N/A，不把 0/0 当 1。

连续任务会产生不同合法实现：预先冻结共同契约与语义裁决规则，不能按 BTAE 的文件布局规定唯一正确实现。参考轨迹只能辅助测试，不能作为唯一结构真值。若必须为实际轨迹追加实体映射，评估者对 arm 盲，保留追加前规则、依据和版本，明确这是对冻结规范的实例化而不是修改标准。

隐藏测试由独立维护者编写，包含正常/边界/回归/架构负例；先验证原始失败、参考修复成功，以及适当的错误修复确实失败，防止坏测试/空断言。Agent 自写测试可以成为产物，不能替代隐藏验收。最终 evaluator 保存 source hash、测试版本、命令、退出码、原始结果和隔离证据。

盲审用随机运行 ID 隐藏组名，文档风格可能泄漏分组，应记录评估者的分组猜测和置信度；不要声称完全盲。成本评审与代码质量评审分开，评审人时间计入评估费用，开发者时间计入工程费用，二者单列避免偷换经济结论。
